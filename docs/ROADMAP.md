# Roadmap

## Phase 0 — Foundation

Audit, architecture, build chain, API boundary, documentation, and test scaffolding. Current milestone; see the implementation plan for verified gate status.

## Phase 1 — Telemetry foundation

Real Windows metrics, background collector, sensor provenance, diagnostic Guardian, settings, tray, logging, and CosmoTech interface. Implemented and retained as the cleaner's measurement foundation.

## Milestone 1 — Working cleaner

- Real full standby-list purge with a narrow UAC helper.
- Capability allowlist, serialized requests, raw native result, and measured before/after result.
- Prominent manual control and bounded session history.
- Runtime verification on the audited Windows build.

Status: implemented; native engine verified on build 26340, UI-driven interaction validation partial.

## Milestone 2 — ISLC functional parity

- Opt-in standby/free-zero thresholds, polling, cooldown, minimum interval, and maximum frequency.
- Excluded applications, cleaner-only pause, tray operation, persistent history, and failure recovery.
- Stable Windows 10/11 validation matrix.

## Phase 3 — Evidence lab

- Bounded historical storage and migrations.
- Performance sessions, annotations, comparable A/B methodology, and export.
- Foreground app and opt-in game profiles.
- PresentMon feasibility/licensing and non-injection integration.
- Modern process-scoped Timer Lab with balanced request/release.

## Phase 4 — Productization

- Compact desktop monitor (not injected game overlay).
- First-run capability scan and onboarding.
- Full accessibility/DPI matrix.
- Installer, signing, update authenticity, recovery, and release channels.
- Stable Windows 10/11 matrix and long-duration resource validation.

No roadmap item implies that clearing cache improves gaming, fixes leaks, or guarantees lower latency.
